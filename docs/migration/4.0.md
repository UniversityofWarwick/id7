4.0 has a major change to use CSS Custom Variables, where previously everything was generated at build time. The big difference as a result is that site-specific branding CSS no longer generates a lot of CSS rules to override the colours of visual elements. Instead it just defines a set of variables, which the base ID7 styles reference.

This change has been made to support continued updates to the brand, but it makes it generally easier to manage and override colours consistently.

The following is just the changes you might need to do to keep your application looking as it did before, and doesn't include any steps to start using the new branding. See the [separate guide](/migration/evolved/).

* If you build your own subset of modules instead of importing `id7` or `id7-no-fa`, ensure you include:
  - `@import 'evolved-brand.less';`
* `apply-brand` now calls `brand-css-variables`, so if you use both of these in your custom theming, you can remove the latter.
* If your custom style is one of the new brand colours, you can choose to instead add the `id7-brand-COLOURNAME` class to your `html` element instead of generating brand.
